# WORLD EVENT SYSTEM — BRIEFING

## 시스템 철학

세계 이벤트는 게임 세계가 길드 외부에서 독자적으로 움직이고 있다는 감각을 부여하기 위한 시스템이다.

플레이어가 직접 관여하거나 제어할 수 없는 사건이지만,
그 결과가 길드 운영에 미묘하게 영향을 미친다.

이벤트의 존재 의미는 다음에 있다.

- 경제·의뢰·모집 환경이 하루하루 조금씩 달라짐
- 같은 플레이를 반복해도 세계 맥락이 다름
- 결재 대기·의뢰 수행 중 배경으로 작동하는 세계 상태

세계 이벤트는 심각한 패널티도, 크나큰 보너스도 아니다.
플레이어가 의식하지 않아도 괜찮고, 의식하면 판단에 활용할 수 있는 레이어다.

---

## 현재 구현 (0019-D)

- 8종 이벤트 (발생·지속·종료 사이클)
- 가중 랜덤 발생, 하루 최대 1개, 최대 3개 동시 활성
- 충돌 그룹 (흉년·풍년 동시 불가 등)
- 창고 판매가 실시간 보정 (warehouse_sale modifier)
- 일일 보고서 시작/종료 알림
- 세계 연대기 기록
- GuildHall 대시보드 이벤트 스트립
- DevPanel 강제 발생 도구

---

## 향후 확장 방향

### 효과 확장

현재는 `warehouse_sale` 효과만 실제 연동되어 있다.
향후 다음 효과도 실제 시스템에 연결할 수 있다.

- `quest_reward` — 의뢰 자동 생성 시스템과 연동
- `recruitment` — 지원자 생성 확률 연동
- `region_danger` — 지역 위험도 연동

### 이벤트 정교화

- 계절 전용 이벤트 (봄 풍작, 겨울 폭설 등)
- 길드 명성 조건부 이벤트
- 특정 시설 보유 조건 이벤트
- 특정 지역과 연결된 지역 이벤트

### 연쇄 이벤트

- 하나의 이벤트가 다른 이벤트를 유발하는 연쇄 구조
- 국경 분쟁 → 난민 지원 의뢰 발생
- 전염병 → 치료 의뢰 급증

### 플레이어 대응

- 이벤트에 길드 자원을 투입하여 효과를 조절
- 이벤트 조기 종료 의뢰 발생
- 이벤트를 활용한 특수 의뢰 발주

### 연대기 확장

- 세계 연대기 전용 탭
- 과거 이벤트 히스토리 조회
- 이벤트 빈도·패턴 통계

### 대형 이벤트

- 다단계 발전 (분쟁 → 전쟁 → 정전)
- 전 지역 영향 이벤트
- 레이드 이벤트 트리거
- 세계 시나리오 연결

---

## 설계 제약

다음 원칙은 향후 확장에서도 유지한다.

- 원본 데이터 (baseValue, 의뢰 보상, 시설 비용) 직접 수정 금지
- 이벤트 효과는 modifier 방식으로만 적용
- 이벤트 종료 후 효과 잔존 금지
- Quest Event Engine과 혼합 금지
- 하루 최대 신규 이벤트 1개 원칙 유지
- 상반된 이벤트 동시 활성화 금지 (conflictGroup 관리)
