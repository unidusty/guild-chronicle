# Guild Chronicle UI Reference

이 문서는 Guild Chronicle UI 레퍼런스의 기준 문서이다.

## 목적

-   레퍼런스 이미지를 그대로 복제하지 않는다.
-   레이아웃과 정보 구조만 참고한다.
-   Guild Chronicle만의 다크 그린 + 골드 스타일을 유지한다.

## 디자인 철학

-   캐릭터 중심 UI
-   정보 계층 우선
-   높은 가독성
-   다크 판타지 분위기

## 공통 원칙

### 레이아웃만 참고

참고: - 정보 배치 - 정보 계층 - 카드 구성 - 여백 - 레이아웃

참고하지 않음: - 색상 - 폰트 - 프레임 - 텍스처 - 버튼 디자인 - 아이콘
디자인

### 캐릭터 우선

항상

캐릭터 → 정보 → 능력

순으로 시선이 흐르도록 설계한다.

### 확장성

현재는 플레이스홀더를 사용하더라도, 향후 반신 일러스트, 아이콘, 프레임만
교체하면 완성될 수 있도록 레이아웃을 설계한다.
