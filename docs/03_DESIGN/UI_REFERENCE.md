# UI REFERENCE

Guild Chronicle UI 레퍼런스 기준서.

---

## 목적

이 문서는 외부 레퍼런스를 참고할 때의 원칙을 정의한다.  
색상·타이포그래피·전체 스타일 기준은 `docs/03_DESIGN/VISUAL_STYLE_GUIDE.md`에 있다.

---

## 레퍼런스 활용 원칙

- 레퍼런스 이미지를 그대로 복제하지 않는다.
- **레이아웃과 정보 구조만** 참고한다.
- Guild Chronicle만의 다크 그린 + 골드 스타일을 유지한다.

참고 항목:
- 정보 배치, 정보 계층, 카드 구성, 여백, 레이아웃

참고하지 않는 항목:
- 색상, 폰트, 프레임, 텍스처, 버튼 디자인, 아이콘 디자인

---

## 디자인 철학

- **캐릭터 중심 UI** — 모험가 초상화와 이름이 화면의 첫 시선을 받는다.
- **정보 계층 우선** — 캐릭터 → 핵심 정보 → 세부 정보 순으로 시선이 흐른다.
- **높은 가독성** — 어두운 배경에서도 텍스트가 명확히 읽힌다.
- **다크 판타지 분위기** — 화려함보다 절제된 품격을 추구한다.
- **확장성** — 플레이스홀더를 사용하더라도 나중에 일러스트·아이콘·프레임만 교체해 완성할 수 있도록 레이아웃을 설계한다.

---

## 레퍼런스 이미지 목록

레퍼런스 이미지는 `docs/03_DESIGN/reference/` 폴더에 보관한다.

### 01_adventurer_list

참고: 목록 레이아웃, 필터, 검색창, 표 기반 목록, 페이지네이션

### 02_adventurer_detail

참고: 좌측 캐릭터 카드, 반신 초상화, 정보 카드, 능력치, 특성, 최근 활동

---

## Claude Code 작업 규칙

작업 시작 전 반드시 `docs/03_DESIGN/reference/` 폴더를 확인한다.

레퍼런스를 복제하지 말고 Guild Chronicle 스타일로 재해석한다.
