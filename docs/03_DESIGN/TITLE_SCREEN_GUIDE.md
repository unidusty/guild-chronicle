# TITLE SCREEN GUIDE

Guild Chronicle 타이틀 화면 설계 기준서.

---

## 현재 상태

타이틀 화면은 아직 구현되지 않았다.  
현재 앱은 진입 시 즉시 길드 홀 화면으로 이동한다. (`App.tsx` → 기본 page: `"guildHall"`)

이 문서는 타이틀 화면을 구현할 때 따를 설계 기준이다.

---

## 설계 목적

타이틀 화면은 플레이어가 게임 세계에 처음 진입하는 관문이다.

- Guild Chronicle의 다크 판타지 분위기를 즉시 전달한다.
- 게임 시작 전 사운드 자동 재생 문제를 자연스럽게 해결한다 (타이틀 클릭 = 첫 사용자 입력).
- 나중에 저장 슬롯, 옵션, 크레딧 메뉴를 추가할 수 있는 구조를 갖춘다.

| 버전 표시 | 현재 버전 번호 | 미구현 |

## 로고 디자인 기준

- 영문 타이틀 `GUILD CHRONICLE`을 세리프 폰트(Georgia 계열)로 표시한다.
- 자간을 넓게 (`letter-spacing: 0.2em` 이상) 설정해 장엄한 느낌을 준다.
- 한국어 부제 `길드 연대기`는 영문 타이틀 아래에 작게, 골드(`#9c8757`) 색상으로 표시한다.
- 장식 선(ruling line)으로 영문과 한국어 부제를 분리한다.
- 배경이 어두울 때: 텍스트는 따뜻한 아이보리(`#e8e5dc`)
- 빛 효과 또는 외곽선은 사용하지 않는다. 글자 자체의 무게로 존재감을 낸다.

## 배경 기준

### 현재 구현 목표 (배경 이미지 없을 때)

```css
background:
  radial-gradient(circle at 50% 30%, #1e2920 0%, transparent 55%),
  radial-gradient(circle at 80% 80%, #191e19 0%, transparent 45%),
  #101411;
```

어두운 숲 혹은 길드 홀 내부를 암시하는 심층적인 다크 그린 그라디언트를 사용한다.

### 향후 배경 이미지 추가 시

- 파일 위치: `public/backgrounds/title-bg.webp`
- 해상도: 최소 1920×1080
- 분위기: 안개 낀 숲, 석조 길드 홀 외벽, 또는 도시 전경 (야경)
- 중앙 로고 영역은 어두운 비네팅으로 가독성 확보
- 파일명 규칙: `{화면명}-bg.webp`

## 메뉴 버튼 규칙

- 버튼은 세로로 배치한다. 가로 정렬 금지.
- 버튼 배경은 투명 또는 반투명. 테두리만 있는 ghost 스타일.
- 활성 버튼: 골드 테두리(`#ac9255`), 텍스트 `#d2bb7e`
- 비활성 버튼 (불러오기): 텍스트 `#4a524c`, 테두리 `#2a2f2b`, 클릭 불가

### 인터랙션

- 마우스 오버: `playHover()` 효과음
- 클릭: `playSelect()` 효과음
- **새 게임 시작** 클릭 → BGM 자동 시작 후 게임 진입

---

## 오디오 연동

타이틀 화면은 브라우저의 자동 재생 제한 문제를 해결하는 역할을 겸한다.

- 타이틀 화면에서 **새 게임 시작** 버튼 클릭 시 첫 사용자 입력으로 처리한다.
- 현재 `useAudio` 훅의 `click` 또는 `keydown` 리스너 로직을 타이틀 진입 시점으로 이전한다.
- 타이틀 BGM을 별도로 재생하는 경우, 게임 진입 시 길드 홀 BGM으로 부드럽게 전환한다.

---

## 버전 표시

- 우측 하단 또는 좌측 하단에 고정 표시한다.
- 형식: `v{버전번호}` (예: `v0.18`)
- 스타일: `color: #4a524c; font-size: var(--font-tiny);`

## 향후 확장

| 기능 | 조건 | 우선순위 |
|------|------|----------|
| 저장 슬롯 선택 UI | 저장 기능 구현 후 | 저장 기능(0019 이후) |
| 타이틀 BGM (별도) | 오디오 에셋 추가 후 | 낮음 |
| 화면 전환 애니메이션 | 타이틀 구현 시 함께 | 낮음 |
| 크레딧 화면 | 별도 요청 시 | 낮음 |

---

## 구현 시 주의사항

- 타이틀 화면은 `App.tsx` 상태 초기화 이전에 표시된다. `GameState`를 필요로 하지 않는다.
- 배경 이미지 없이도 CSS 그라디언트만으로 분위기를 유지할 수 있어야 한다.
- 불러오기 버튼은 저장 기능이 구현될 때까지 비활성 상태로만 표시한다. 버튼을 숨기지 않는다.
