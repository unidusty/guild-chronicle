# 세계 시스템 가이드

## 목적

Guild Chronicle의 세계 구조를 정의한다.
세계는 의뢰의 배경이자 몬스터·세력·사건의 무대다.
플레이어는 세계를 직접 탐험하지 않는다. 파티를 파견하고 그 결과로 세계와 간접적으로 상호작용한다.

현재 구현에서 지역(Region)은 의뢰의 위치 데이터로만 사용된다.
세계 지도, 세력 상호작용, 지역 발전 등은 0026 이후에 구현된다.

---

## 세계 구조 개요

```
대륙
└── 국가 (왕국·공화국·부족연합 등)
    ├── 수도 (대도시)
    ├── 도시 (중소 거점)
    │   └── 마을 (도시 종속 소규모 취락)
    └── 지역 (Region) ← 현재 게임의 기본 위치 단위
        ├── 던전
        ├── 유적
        └── 야생 지대
```

지역(Region)이 게임의 기본 위치 단위다.
의뢰는 반드시 하나의 지역에 귀속된다.

---

## 대륙

현재 게임 배경의 대륙 이름은 미확정이다.

아르테니아 왕국이 위치한 대륙. 인간·엘프·드워프가 혼재하는 다종족 문명권.
대륙 북부는 미개척 황야로, 드래곤과 고대 마수의 영역이다.
대륙 중부에 왕국 문명권이 밀집해 있다.

---

## 국가

### 아르테니아 왕국

게임 배경의 주요 국가.

| 항목 | 내용 |
|------|------|
| 정체 | 왕국 |
| 현재 연도 | 왕국력 317년 (게임 시작 기준) |
| 수도 | 아르테니아 왕도 |
| 특징 | 대륙 중부 지배. 모험가 길드 제도 공식 인정 |

길드의 본거지는 왕도에서 서쪽으로 이어지는 국경 방면 거점 도시다.

---

## 도시

왕국 내 주요 도시는 의뢰 발주·정보 수집·물자 교역의 거점이다.

| 구분 | 설명 |
|------|------|
| 대도시 (수도 포함) | 왕실·귀족·상인 길드 중심. 고위 의뢰·공식 거래 |
| 중간 거점 도시 | 지역 행정 중심. 일반 의뢰·모험가 교류 |
| 국경 도시 | 위험 지역 인접. 긴급 의뢰·군사 지원 요청 잦음 |

### 길드 소재 도시

현재 길드가 위치한 도시. 이름 미확정.
왕국 서쪽 국경 방면 중간 거점 도시로 설정된다.
서쪽 들판·서부 수로 등 안전 지역과 국경 방면 위험 지역 사이에 위치한다.

---

## 마을

도시에 종속된 소규모 취락.

- 농촌·어촌·광산촌 등 단일 산업 중심 구성
- 단독으로 의뢰를 발주할 수 없음. 도시를 통해 의뢰 접수
- 마을 자체가 의뢰의 목적지(구조·호위 등)가 될 수 있음

---

## 지역 (Region)

게임의 기본 위치 단위. 모든 의뢰는 하나의 지역에 귀속된다.

### 현재 구현 데이터 구조

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string | `"region-{영문식별자}"` |
| `name` | string | 표시용 한국어 지역명 |
| `danger` | number | 위험도 수치 (0~100) |
| `control` | string | 지배 상태 |

### 지배 상태 (control)

| 값 | 표시 | 설명 |
|----|------|------|
| `kingdom` | 왕국 통제 | 왕국 치안력 작동. 상대적 안전 |
| `contested` | 분쟁 지대 | 왕국과 세력·몬스터 간 경합 |
| `hostile` | 적대 지역 | 왕국 영향력 없음. 극히 위험 |

### 지역 유형 (향후 추가 예정)

| 값 | 표시 | 예시 |
|----|------|------|
| `city_area` | 도시 지역 | 왕도 외곽·도시 내부 |
| `plain` | 평원 | 서쪽 들판 |
| `forest` | 숲 | 어둠의 숲 |
| `mountain` | 산악 | 회색등성이, 북부 산맥 |
| `swamp` | 늪지 | 늪지대 |
| `coast` | 해안·수로 | 서부 수로 |
| `dungeon` | 던전·폐광 | 폐광 지대 |
| `ruins` | 유적 | 고대 유적 |
| `canyon` | 협곡 | 붉은 협곡 |
| `border` | 국경 지대 | 국경 고갯길 |

상세 데이터: `docs/02_DATABASE/REGION_DATABASE.md` 참조.

## 길드 지부

모험가 길드는 단일 길드가 아니라 왕국 전역에 지부를 운영하는 연합 조직이다.

| 항목 | 내용 |
|------|------|
| 플레이어 역할 | 지부 마스터 (하나의 지부 운영) |
| 타 지부 | NPC 운영 (향후 경쟁·협력 관계 구현) |
| 공통 규약 | 의뢰 등급 기준, 모험가 신원 확인, 분쟁 조정 |

지부 간 관계는 0026 이후에 구현된다.

---

## 세력 (Faction)

세계의 다양한 정치·군사·종교·몬스터 집단.

| 종류 | 예시 |
|------|------|
| 국가 | 아르테니아 왕실, 인접 국가 |
| 귀족 | 각지 영주·귀족 가문 |
| 기사단 | 왕국 정규기사단, 종교 기사단 |
| 상인 길드 | 왕국 상인 연합, 밀수 조직 |
| 마탑 | 왕립 마법사 탑 |
| 종교 | 빛의 성교회, 지역 신앙 |
| 범죄 조직 | 국경 도적단, 도시 하층 조직 |
| 몬스터 세력 | 고블린 왕국, 드래곤 세력 |

세력은 길드와 관계를 형성하고 의뢰 발주·협조·방해의 원천이 된다.
세력 간 관계는 세계 이벤트와 역사에 영향을 미친다.

상세 데이터: `docs/02_DATABASE/FACTION_DATABASE.md` 참조.

## 종족

현재 플레이어블 종족 3종이 정의되어 있다.

| 종족 | 특징 | 길드 내 역할 |
|------|------|-------------|
| 인간 | 적응력·다양성. 가장 많음 | 전 직업 |
| 엘프 | 장수·민첩·마법 친화 | 궁수·마법사 중심 |
| 드워프 | 강인함·완고함·수공예 | 전사·수호자 중심 |

추가 종족은 향후 확장에서 정의된다.

## 지역 위험도

지역의 몬스터·적대 세력 위협 수준.

### 현재 구현

`danger` 필드: 0~100 수치.
이 수치는 의뢰 성공률 계산에 사용된다.

### 향후 구현 (0026)

몬스터 군락 기반 0~5 단계 위협도로 전환.
계절·군락 현황에 따라 매 계절 갱신.

→ 상세: `docs/01_SYSTEM/MONSTER_SYSTEM_GUIDE.md`

---

## 몬스터 군락과 연동

지역은 복수의 몬스터 군락을 포함할 수 있다.
군락의 규모와 랭크가 지역 위험도를 결정한다.
지역 위험도가 일정 수준 이상이면 토벌·소탕 의뢰가 자동 생성된다.

→ 상세: `docs/02_DATABASE/MONSTER_COLONY_GUIDE.md`

---

## 의뢰 생성과의 연동

### 현재 구현

의뢰는 `regionId`로 지역에 연결된다.
지역의 `danger`·`control` 값이 이벤트 태그 파생에 사용된다.

### 향후 구현 (0026 이후)

- 지역 상황에 따른 의뢰 자동 생성
- 지역별 의뢰 후보 풀 차별화
- 지역 기반 의뢰 유형 제한 (예: 해안 지역에서 탐사 의뢰 빈도 상승)

---

## 교역 시스템과의 연동

교역 시스템은 0025 이후 구현 예정.

- 도시 간 교역로가 지역을 연결한다
- 교역로 안전도가 호위·배달 의뢰 발생률에 영향
- 지역 특산물이 교역 품목이 된다
- 길드는 물자 운반·교역 보호 의뢰를 수주할 수 있다

---

## 경제와 자원

각 지역은 고유한 자원·산업·특산물을 가진다.

| 자원 유형 | 예시 |
|-----------|------|
| 광물 | 철광·은광·마석 광맥 |
| 식량 | 곡물·목축·어업 |
| 마법 재료 | 약초·희귀 광물·몬스터 소재 |
| 기술 | 단조·연금술·조선 |

자원은 길드 창고 전리품과 연결되며 판매·가공·교역의 기반이 된다.

---

## 세계 이벤트

세계 규모의 사건이 지역과 의뢰에 영향을 준다.

| 이벤트 유형 | 영향 |
|-------------|------|
| 왕국 축제 | 의뢰 감소·금 보상 상승 |
| 흉년 | 식량 의뢰 급증·길드 유지비 상승 |
| 전염병 | 이동 제한·구조 의뢰 폭증 |
| 몬스터 대발생 | 특정 지역 위협도 급상승·긴급 토벌 |
| 전쟁 발발 | 지역 장악권 변화·군사 의뢰 등장 |
| 재난 | 구조·복구 의뢰 폭증 |

세계 이벤트는 0019 랜덤 세계 이벤트에서 첫 구현된다.

## 계절과 시간

### 현재 구현

- 1년 = 봄·여름·가을·겨울 4계절 × 30일 = 120일
- 계절은 이벤트 엔진의 태그(`season:*`)로 활용된다

### 세계 연동 (향후)

| 계절 | 세계 영향 |
|------|-----------|
| 봄 | 몬스터 번식 활성화·여행 의뢰 증가 |
| 여름 | 활동 최대·야외 의뢰 최다 |
| 가을 | 상단 호위·식량 배달 급증 |
| 겨울 | 언데드 활성화·이동 의뢰 감소·실내 의뢰 증가 |

---

## 지역 이동

파티가 의뢰를 수행하기 위해 지역으로 이동하는 규칙.

### 현재 구현

이동 일수는 의뢰의 전체 기간에 포함되어 있다.
지역 간 거리는 별도로 정의되어 있지 않다.

### 향후 구현 (0021 동적 의뢰 기간, 0026 세계 시스템)

- 지역 간 거리 수치 정의
- 이동 수단에 따른 이동 시간 차이
- 이동 중 이벤트 발생
- 지역 기반 이동 시간을 의뢰 기간 생성에 반영

---

## 지역 발전

길드 활동이 지역에 영향을 준다. 향후 구현 예정 (0026, 0029).

| 행동 | 지역 변화 |
|------|-----------|
| 몬스터 군락 토벌 | 위협도 감소·이주민 유입·의뢰 품질 상승 |
| 교역로 보호 성공 | 교역 활성화·도시 성장 |
| 지역 의뢰 연속 수주 | 지역 평판 상승·특별 의뢰 등장 |
| 몬스터 방치 | 위협도 상승·주민 피해·의뢰 품질 하락 |

---

## 세계 변화

세계는 정적이지 않다. 이벤트·길드 활동·시간 경과에 따라 변한다.

| 변화 종류 | 예시 |
|-----------|------|
| 정치 변화 | 왕위 계승·전쟁·협정 |
| 지역 변화 | 도시 성장·쇠퇴·함락·복구 |
| 생태 변화 | 몬스터 세력 확장·영역 이동 |
| 경제 변화 | 교역로 변화·자원 고갈·신규 광맥 발견 |
| 문화 변화 | 종교 세력 확산·귀족 몰락 |

세계 변화는 의뢰 풀과 이벤트 발생 확률에 직접 반영된다.
