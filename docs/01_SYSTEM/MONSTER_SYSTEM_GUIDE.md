# 몬스터 시스템 가이드

## 개요

몬스터는 의뢰의 위험 요소이자 세계 생태계의 구성 요소다.
플레이어는 몬스터를 직접 조작하거나 전투를 진행하지 않는다.
몬스터는 세계에 실재하며 의뢰·이벤트·지역 위협도를 통해 길드 운영에 영향을 준다.

---

## 몬스터 분류 체계

### 카테고리 (MonsterCategory)

| 값 | 표시 | 설명 | QuestTag |
|----|------|------|----------|
| `undead` | 언데드 | 죽은 자가 되살아난 존재. 신성 속성에 약함 | `enemy:undead` |
| `beast` | 마수 | 마법적으로 변이한 동물. 본능 중심 행동 | `enemy:beast` |
| `goblin` | 고블린 | 소형 지능 생명체. 집단 행동 선호 | `enemy:goblin` |
| `monster` | 마물 | 분류 불명의 마법 기원 생명체 | `enemy:monster` |
| `dragon` | 드래곤 | 드래곤 계열. 최상위 포식자 | `enemy:dragon` |
| `golem` | 골렘 | 마법으로 생성된 구조체. 창조주 명령에 따름 | `enemy:golem` |
| `rodent` | 설치류 | 변이한 설치류. 소형이나 집단 위협 | `enemy:rodent` |
| `humanoid` | 인간형 | 인간에 가까운 지능 보유. 오크·트롤 등 | `enemy:bandit` |

### 종 (Species)

카테고리 내의 구체적인 생물 종. 예: 고블린, 홉고블린, 고블린 샤먼.

### 변종 (Variant)

같은 종이 환경·마법의 영향으로 변이한 형태.
기반 종의 전투 데이터를 따르며 일부 수치와 특수 행동만 조정한다.

---

## 개체 랭크

모험가 랭크와 동일한 기준을 사용한다.
같은 랭크의 파티를 기준 전력으로 삼는다.

| 랭크 | 위협 수준 | 설명 | 예시 |
|------|-----------|------|------|
| F | 최하급 | 일반 성인도 대응 가능 | 대형 쥐, 슬라임, 스켈레톤 |
| E | 하급 | 신입 모험가 수준 필요 | 고블린, 좀비, 하피 |
| D | 중급 | 숙련 모험가 수준 | 오크, 트롤, 석재 골렘 |
| C | 상급 | 베테랑 파티 필요 | 오우거, 리치, 만티코어 |
| B | 최상급 | 엘리트 파티 수준 | 드레이크, 와이번, 뱀파이어 경 |
| A | 재해급 | 복수 파티 + 길드 총력 | 고대 드래곤, 데스 나이트 |
| S | 전설급 | 국가 단위 대응 필요 | 신화적 존재 |

## 크기 등급 (MonsterSize)

| 값 | 표시 | 기준 |
|----|------|------|
| `tiny` | 극소형 | 고양이 이하 |
| `small` | 소형 | 개~어린이 수준 |
| `medium` | 중형 | 성인 인간 수준 |
| `large` | 대형 | 말~곰 수준 |
| `huge` | 거대 | 코끼리 이상 |
| `colossal` | 초거대 | 건물 규모 이상 |

## 서식지 태그

기존 `QuestTag`의 `terrain:*` 값을 그대로 사용한다.

`forest` / `mountain` / `dungeon` / `plain` / `swamp` / `coast` / `city` / `ruins`

몬스터는 복수의 서식지를 가질 수 있다.

---

## 지역 위협도

지역의 몬스터 위협 수준을 나타내는 0~5 단계 수치.
군락 현황과 출몰 빈도를 기반으로 매 계절 갱신된다.

| 단계 | 표시 | 설명 |
|------|------|------|
| 0 | 안전 | 몬스터 없음 또는 극미량 |
| 1 | 낮음 | 소규모 해충·하급 개체 산발적 출몰 |
| 2 | 주의 | 중급 이하 군락 형성. 상시 출몰 |
| 3 | 위험 | 중~상급 군락. 여행자·마을 피해 발생 |
| 4 | 고위험 | 상급 이상 세력 확립. 정규 군대 지원 수준 |
| 5 | 재해 | A랭크 이상 개체 또는 대규모 군락. 국가 개입 수준 |

### 위협도에 따른 의뢰 생성

| 위협도 | 의뢰 유형 | 권장 등급 |
|--------|-----------|-----------|
| 1 | 방제·구제 | F~E |
| 2 | 토벌 | E~D |
| 3 | 소탕 | D~C |
| 4 | 대토벌 | C~B |
| 5 | 긴급 토벌 | B~S |

## 계절 갱신

계절이 바뀔 때 지역별 몬스터 군락이 갱신된다.
상세 규칙은 `docs/02_DATABASE/MONSTER_COLONY_GUIDE.md` 참조.

| 계절 | 특이사항 |
|------|----------|
| 봄 | 번식 활성화. 고블린·설치류 급증. 마수 새끼 등장 |
| 여름 | 활동 최대화. 영역 확장. 이동성 증가 |
| 가을 | 식량 확보 공격 증가. 마을·농장 침입 빈도 상승 |
| 겨울 | 대부분 활동 감소. 지하·동굴 집중. 언데드만 활성화 |

## 의뢰 연동

### QuestTag 매핑

몬스터 카테고리는 `enemy:*` 태그로 변환되어 이벤트 엔진·어드벤처 로그에서 사용된다.
`Quest.enemyHint` 필드에 몬스터 종 이름을 기록하면 관련 이벤트 가중치가 상승한다.

### enemyHint 작성 규칙

- 한국어 종 이름을 그대로 사용한다.
- 복수종이면 가장 위험한 종을 우선 기재한다.
- 변종은 기반 종 이름 뒤에 변종 표시를 붙인다. 예: `"고블린 샤먼"`

---

## 정보 공개 단계

길드가 보유한 해당 종에 대한 정보 수준.
의뢰 완료 시 해당 몬스터 정보가 1단계 상승한다.

| 단계 | 표시 | 공개되는 정보 |
|------|------|---------------|
| 0 | 미확인 | 이름·카테고리 미상 |
| 1 | 목격 | 이름·카테고리·랭크·서식지 |
| 2 | 조사 | + 크기·특수 행동·약점 |
| 3 | 전투 | + 전투 행동 패턴·전리품 목록 |
| 4 | 완전 | 모든 정보. 생태·계절 행동 포함 |

F·E 랭크 몬스터는 초급 모험가 가이드북 수록 기준으로 기본 1단계에서 시작한다.

---

## 설계 원칙

- 몬스터는 세계의 생태계 요소다. 단순한 전투 장애물이 아니다.
- 몬스터 데이터는 이벤트 엔진·서사 생성·의뢰 생성의 근거 자료로 사용된다.
- 새 몬스터를 추가하면 `MONSTER_DATABASE.md`와 `MONSTER_COLONY_GUIDE.md`를 함께 업데이트한다.
- 몬스터 랭크는 모험가 랭크와 항상 대응 관계를 유지한다.
- S랭크 몬스터는 특별 시나리오용으로만 존재한다. 일반 의뢰에 등장하지 않는다.
