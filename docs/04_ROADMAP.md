# 04. ROADMAP

## 완료

**001** 프로젝트 기획 기반
- 비전, 시스템, 규칙, 개발 원칙, 폴더 구조

**002** 기술 스택 및 실행 프로젝트
- Vite + React 19 + TypeScript 5.8, 기본 대시보드 뼈대

**003–004** 데이터 구조 및 에셋 파이프라인
- GameState 설계, 에셋 스캔 및 매니페스트 자동 생성

**005–006** 모험가 생성 및 관리
- 랜덤 생성, 목록, 상세 화면, 전투 능력·성향

**007–009** 초상화·레이아웃·상세 UI 개선
- 초상화 직접 경로 방식, 모험가 상세 탭 구조, 연대기 더미 데이터

**010–010-A** 오디오 시스템
- BGM 재생, UI 효과음, 사운드 설정 화면

**011** 시간 진행 시스템 1차
- 하루 진행, 날짜·계절·연도 증가

**011-B** 모험가 UI 정리
- 잠재력 컬럼 제거, 별점 가독성 개선

**011-C** 하루 진행 의뢰 연동
- 의뢰 남은 일수 감소, 진행률 증가, 완료 처리, 모험가 복귀, 연대기 기록

**011-D** 프로젝트 문서 현행화

**011-E** 시간 흐름 기본 완성
- 해 바뀜 시 모험가 나이 증가
- 부상 회복 일수 감소 및 완료 처리
- 훈련 남은 일수 감소 및 완료 처리
- 완료 사건 연대기 기록

**012-A** 파티 관리 기반 및 모험가 풀 확장
- 기본 모험가 12명으로 확장
- 파티 목록 화면 (카드 형식)
- 파티 상세 표시 (파티원, 리더, 진행 의뢰)

**012-B** 파티 생성 및 편성
- 새 파티 생성 (이름 입력)
- 모험가 배치·제외, 리더 지정
- 파견 중 파티 수정 제한
- 대시보드 패널 고정 높이 + 내부 스크롤

**012-C** 랭크 시스템 및 파티 유대 기반
- 파티 이름 인라인 변경 (파티 상세, 2~20자, 이름 변경 이력 구조)
- "등급" → "랭크" 용어 전면 변경 (모험가 목록, 파티 상세, 대시보드)
- 신규 모험가 기본 F랭크
- 파티 랭크 자동 계산 (파티원 평균 플로어, 편성 변경 시 재계산)
- 파티 유대 기초: currentFormationDays (매일 +1), currentFormationQuestCount (의뢰 완료 시 +1)
- 편성 변경 시 유대 리셋 (멤버 추가·제외·리더 변경·파티 생성)
- PartyHistory 구조 (리셋 시 이전 편성 기록 보존)
- 파티 상세 유대 단계 표시 (신생 파티 / 호흡을 맞추는 중 / 익숙한 동료들 / 숙련된 팀워크 / 오랜 전우)

## 예정

**013-A** 의뢰 게시판 UI 기반
- 의뢰 게시판 화면 (목록 + 상세 2열 레이아웃)
- QuestType (normal/urgent/raid), QuestCategory, QuestStatus("in_progress" 추가) 타입 확장
- Quest 타입 확장: description, clientName, dangerLevel, recommendedPartySize, expiresInDays
- 12개 샘플 의뢰 (F×2, E×2, D×2, C×1, B×2, S×1 + 기존 2개)
- 10개 지역 데이터 (기존 2 + 신규 8)
- 상태 필터 (전체/접수 가능/수행 중/완료) + 랭크 필터 (F~S) 정상 작동
- 의뢰 상세: 의뢰인·지역·보상·소요기간·위험도·권장인원·접수기한·설명·위험요소 표시
- 파티 배정 버튼 (클릭 시 013-B 안내 표시)
- 긴급/대형 의뢰 배지 표시
- 목록·상세 내부 스크롤 정상

**014** 의뢰 수락 및 파티 배정
- 의뢰 선택, 파티 선택, 출발 처리
- 모험가 상태 변경, 연대기 기록

**015** 의뢰 결과 및 보상
- 성공·실패 판정, 보상 지급, 부상 판정
- 전리품, 평판 변화, 귀환 연대기
