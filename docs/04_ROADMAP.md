# 04. ROADMAP

## 완료

**001** 프로젝트 기획 기반
- 비전, 시스템, 규칙, 개발 원칙, 폴더 구조

**002** 기술 스택 및 실행 프로젝트
- Vite + React 19 + TypeScript 5.8, 기본 대시보드 뼈대

**003–004** 데이터 구조 및 에셋 파이프라인
- GameState 설계, 에셋 스캔 및 매니페스트 자동 생성

**005–006** 모험가 생성 및 관리
- 랜덤 생성, 목록, 상세 화면, 전투 능력·성향

**007–009** 초상화·레이아웃·상세 UI 개선
- 초상화 직접 경로 방식, 모험가 상세 탭 구조, 연대기 더미 데이터

**010–010-A** 오디오 시스템
- BGM 재생, UI 효과음, 사운드 설정 화면

**011** 시간 진행 시스템 1차
- 하루 진행, 날짜·계절·연도 증가

**011-B** 모험가 UI 정리
- 잠재력 컬럼 제거, 별점 가독성 개선

**011-C** 하루 진행 의뢰 연동
- 의뢰 남은 일수 감소, 진행률 증가, 완료 처리, 모험가 복귀, 연대기 기록

**011-D** 프로젝트 문서 현행화

**011-E** 시간 흐름 기본 완성
- 해 바뀜 시 모험가 나이 증가
- 부상 회복 일수 감소 및 완료 처리
- 훈련 남은 일수 감소 및 완료 처리
- 완료 사건 연대기 기록

**012-A** 파티 관리 기반 및 모험가 풀 확장
- 기본 모험가 12명으로 확장
- 파티 목록 화면 (카드 형식)
- 파티 상세 표시 (파티원, 리더, 진행 의뢰)

**012-B** 파티 생성 및 편성
- 새 파티 생성 (이름 입력)
- 모험가 배치·제외, 리더 지정
- 파견 중 파티 수정 제한
- 대시보드 패널 고정 높이 + 내부 스크롤

**013** 의뢰 게시판 ← 현재
- 의뢰 목록 및 상세
- 등급, 권장 전투력, 예상 기간, 보상, 위험 요소

**014** 의뢰 수락 및 파티 배정
- 의뢰 선택, 파티 선택, 출발 처리
- 모험가 상태 변경, 연대기 기록

**015** 의뢰 결과 및 보상
- 성공·실패 판정, 보상 지급, 부상 판정
- 전리품, 평판 변화, 귀환 연대기
