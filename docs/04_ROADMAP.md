# 04. ROADMAP

## 완료

**001** 프로젝트 기획 기반
- 비전, 시스템, 규칙, 개발 원칙, 폴더 구조

**002** 기술 스택 및 실행 프로젝트
- Vite + React 19 + TypeScript 5.8, 기본 대시보드 뼈대

**003–004** 데이터 구조 및 에셋 파이프라인
- GameState 설계, 에셋 스캔 및 매니페스트 자동 생성

**005–006** 모험가 생성 및 관리
- 랜덤 생성, 목록, 상세 화면, 전투 능력·성향

**007–009** 초상화·레이아웃·상세 UI 개선
- 초상화 직접 경로 방식, 모험가 상세 탭 구조, 연대기 더미 데이터

**010–010-A** 오디오 시스템
- BGM 재생, UI 효과음, 사운드 설정 화면

**011** 시간 진행 시스템 1차
- 하루 진행, 날짜·계절·연도 증가

**011-B** 모험가 UI 정리
- 잠재력 컬럼 제거, 별점 가독성 개선

**011-C** 하루 진행 의뢰 연동
- 의뢰 남은 일수 감소, 진행률 증가, 완료 처리, 모험가 복귀, 연대기 기록

**011-D** 프로젝트 문서 현행화

**011-E** 시간 흐름 기본 완성
- 해 바뀜 시 모험가 나이 증가
- 부상 회복 일수 감소 및 완료 처리
- 훈련 남은 일수 감소 및 완료 처리
- 완료 사건 연대기 기록

**012-A** 파티 관리 기반 및 모험가 풀 확장
- 기본 모험가 12명으로 확장
- 파티 목록 화면 (카드 형식)
- 파티 상세 표시 (파티원, 리더, 진행 의뢰)

**012-B** 파티 생성 및 편성
- 새 파티 생성 (이름 입력)
- 모험가 배치·제외, 리더 지정
- 파견 중 파티 수정 제한

**012-C** 랭크 시스템 및 파티 유대 기반
- 파티 이름 인라인 변경 (2~20자)
- "등급" → "랭크" 용어 전면 변경
- 신규 모험가 기본 F랭크
- 파티 랭크 자동 계산 (파티원 평균 플로어)
- 파티 유대 기초: currentFormationDays / currentFormationQuestCount
- 편성 변경 시 유대 리셋 + PartyHistory 구조

**013-A** 의뢰 게시판 UI 기반
- 의뢰 게시판 화면 (목록 + 상세 2열 레이아웃)
- QuestType, QuestCategory, QuestStatus 타입 확장
- 샘플 의뢰 12개, 10개 지역 데이터
- 상태/랭크 필터, 의뢰 상세 표시

**016-A~D** 길드 홀 구조 개편 + 일일 보고서 + 가입 심사 + 창고
- 사이드바 네비게이션 전면 개편 (7개 메뉴)
- 길드 홀 3탭 (대시보드 / 시설 / 가입 심사)
- 오늘 업무 종료 2단계 UI + 일일 운영 보고서
- 가입 심사 시스템 (지원자 생성, 승인/보류/반려)
- 길드 창고 (전리품 보관, 판매)

**018-A** 의뢰 수락 및 파티 배정 기반
- 파티 선택 UI, 의뢰 배정 처리
- 랭크 적합성 검사, 도전 모드
- 권장 전투력 계산 (`calcPartyCombatPower`)

**018-B** 의뢰 진행 시스템
- QuestProgress 타입 (단계, 이벤트, 결정)
- 의뢰 진행 3단계: 이동 → 수행 → 귀환
- 현장 이벤트 생성 (확률적, 카테고리별)
- 플레이어 결정 (계속/철수/지원 파견)

**018-C** 진행 중 의뢰 UI
- ActiveQuestsTab: 목록 + 우측 상세 패널
- 진행 단계·이벤트·결정 표시
- 지원 파견 파티 선택 UI
- 예상 성공률·현재 위험도 표시

**018-D** 의뢰 결과 및 보상
- QuestResultGrade (6단계)
- 성공률 계산, 골드 보상 배율
- QuestChronicleEntry, 의뢰 연대기 탭
- 전리품 드롭, 보상 결과 팝업

**018-E** 의뢰 게시판 UI 개편
- 3탭 구조 (가능 의뢰 / 진행 중 의뢰 / 의뢰 연대기)
- 카드 그리드, 랭크 칩 필터, 정렬
- 전체 CSS 스타일링

**018-F** 모험 기록 (Adventure Log)
- AdventureLogEntry 타입 + GameState 연동
- adventureLog.ts: 출발·일별·이벤트·결정·완료 기록 생성
- 결정적 해시 기반 템플릿 선택 (동일 입력 → 동일 문장)
- 의뢰 상세 + 의뢰 연대기 탭에 모험 기록 표시
- 의뢰 카드 클릭 효과음 (종이 펼침)

**018-G** 의뢰 시스템 최종 마감
- 의뢰 상세 모달 전환 (우측 패널 → 중앙 오버레이)
- 오디오 경로 수정 (`/audio/ui-quest-paper-open.mp3`)
- 프로젝트 문서 현행화 (docs 9개 + 설계 가이드 4개)
