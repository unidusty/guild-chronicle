## 예정

**0020** 길드 재정 확장 및 랜덤 이벤트

### 길드 재정 (잔여)
- 길드 운영 자금
- 시설 유지비
- 시설 업그레이드 비용
- 길드 세금 및 운영비
- 의뢰 실패 패널티
- 길드 평판에 따른 보상 변동
- 숙박 수익
- 식사 수익
- 펍 수익
- 전리품 판매 수익

### 외부 의뢰 보수 정산
- 외부 의뢰 보수는 길드의 전체 수입이 아님
- 길드는 최종 지급 보수의 기본 10%를 중개 수수료로 취득
- 나머지 90%는 실제 의뢰를 수행한 파티에 지급
- 길드는 파티 단위까지만 정산하며 파티 내부 분배에는 관여하지 않음
- 지원 파티가 참여한 경우 주 파티와 지원 파티 사이 정산 기준 적용
- 결과 화면에 총 보수·길드 수수료·파티 지급액을 구분 표시
- 철수·실패·부분 성공 시 실제 지급액과 수수료를 결과에 맞게 조정
- 의뢰 연대기에 발주 주체와 정산 내역 기록

### 길드 직접 발주 의뢰
- 외부 의뢰 중개와 별도로 길드가 직접 의뢰를 발주할 수 있음
- 길드 발주 의뢰에는 중개 수수료가 없음

### 의뢰 기간 생성 규칙

#### 기본 원칙
- 의뢰의 전체 기간을 무작위로 분배하지 않음
- 일반 의뢰는 이동 → 수행 → 귀환의 3단계 구조를 기본으로 함
- 수행 단계가 전체 기간에서 가장 큰 비중을 차지
- 거리·지역·의뢰 유형·난이도·목표 복잡도·계절·기상을 함께 반영
- 생성된 기간은 확정값이 아니라 0019 동적 의뢰 기간의 최초 예상값으로 사용

#### 권장 기간 범위
- 도시 내부 초급 의뢰: 전체 2~4일
- 근교 초급 의뢰: 전체 3~6일
- 일반 지역 의뢰: 전체 5~10일
- 중거리 위험 의뢰: 전체 10~20일
- 장거리 원정: 전체 20~40일 이상
- 대형 원정·레이드: 수십 일~수개월

#### 단계별 예시
- 하수구 쥐 토벌: 이동 0~1일 / 수행 1~2일 / 귀환 0~1일
- 5일 일반 의뢰: 이동 1일 / 수행 3일 / 귀환 1일
- 8일 일반 의뢰: 이동 2일 / 수행 4~5일 / 귀환 1~2일
- 중·장거리 의뢰: 이동 2~5일 / 수행 6~10일 / 귀환 2~5일
- 대형 원정: 이동 7일 이상 / 수행 10일 이상 / 귀환 7일 이상

#### 호위 의뢰 예외
- 호위는 이동 자체가 수행이므로 일반 의뢰와 다른 기간 규칙 사용
- 출발 → 이동 중 사건 → 방어 → 목적지 도착 → 길드 귀환 → 보고 구조
- 호위 거리와 이동 경로가 핵심 수행 기간을 결정

#### 안전 규칙
- 짧은 초급 의뢰가 사건 하나로 비정상적으로 장기화되지 않도록 상한 설정
- 기간 단축으로 Mandatory Event가 생략되지 않도록 검증
- 이동이나 귀환이 수행 기간보다 과도하게 길어지는 조합 방지
- 장거리·대형 원정만 장기간 이동·귀환을 허용
- 0019 Dynamic Quest Duration과 연동하여 실제 완료일은 진행 중 변경 가능

**0024** 전술 진형 및 전투 시뮬레이션

### 전술 진형
- 기본 진형은 3×3 또는 3×5 구조로 설계
- 데이터 구조는 3×5를 기준으로 하고 작은 길드 단계에서는 일부 슬롯만 개방하는 방식 검토
- 전열·중열·후열뿐 아니라 좌·중앙·우 위치에 실제 의미 부여
- 중앙 전열 탱커는 넓은 도발·보호 범위를 가짐
- 전열의 빈 라인은 적의 침투 경로가 됨
- 후열 노출·측면 압박·전열 붕괴를 실제 판정에 반영
- 직업별 권장 위치와 위치 보정
- 적 유형별 공격 경로와 진형 공략 방식 구현

### Battle Event
- 전투에서 실제로 발생한 행동을 턴 또는 시간 순서로 저장
- battleId / turn / actorId / targetIds
- actionType / sourcePosition / targetPosition
- success / failure / critical
- 피해·회복·보호·상태 효과
- 관련 Quest Tag·특성·장비
- narrativeKey와 중요도
- 텍스트 중계·2D 재생·Adventure Log·연대기에 동일 데이터 사용

### 실시간 전투 텍스트 중계
- 의뢰 중 전투 발생 시 별도 중계 화면 표시
- 실제 Battle Event 순서대로 전투 상황 출력
- 일시 정지
- 1배속 / 2배속 / 4배속
- 주요 장면만 보기
- 전체 전투 건너뛰기
- 전투 종료 요약
- 중요 Battle Event를 Adventure Log 장면으로 변환
- 전투 결과를 먼저 계산한 뒤 중계하는 시뮬레이션·리플레이 구조 사용

### 지원 파티 합동 진형
- 지원 파티 도착 전에는 기존 주 파티 진형만 사용
- 지원 파티 도착 시 해당 의뢰 전용 합동 진형 편성
- 합류 순간 전투를 일시 정지하고 재배치 기회 제공
- 자동 배치와 수동 재배치 모두 지원
- 1파티 3×5, 2파티 5×5 등 참여 파티 수에 따른 전장 확장 검토
- 3파티 이상과 공격대는 별도 대형 진형으로 확장
- 의뢰 종료 후 각 파티는 원래 진형으로 복귀
- 합류 이후 Battle Event와 Adventure Log는 합동 진형을 기준으로 생성

### 역할 아이콘 기반 2D 자동 전투 준비
- 텍스트 전투 중계와 Battle Event 완성 후 구현
- 탱커: 방패 아이콘

- 새로운 전투 판정을 만들지 않고 저장된 Battle Event를 재생
- 전투 다시보기와 하이라이트 확장 준비
