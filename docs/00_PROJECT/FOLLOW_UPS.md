# FOLLOW_UPS — 후속 작업 목록

0020 마일스톤에서 설계되었으나 구현 범위 밖으로 남긴 항목들.
우선순위 없이 카테고리별로 분류.

---

## 0020-F 후속 (길드 직접 발주 의뢰)

- **지원 파견 추가 원정 비용** — 길드 발주 의뢰에서 지원 파견 결정 시 추가 비용 처리 (현재 cost 없음)
- **외부 길드 위탁** — 처리 불가 의뢰를 타 길드에 넘기는 흐름
- **반복 의뢰** — 동일 의뢰를 주기적으로 재등록하는 구조
- **국가·세력 발주** — 세력 관계에 따른 의뢰 등장 (내부 발주 확장)

---

## 0020-E 후속 (길드 운영 경제)

- **시설 수익 실제 콘텐츠** — 여관·펍·식당 `FacilityUsageRecord` 현재 no-op; 실제 수익 계산 연결 필요
- **의뢰 실패 패널티** — 실패 시 길드 자금 차감 또는 명성 손실 연동
- **미납 이자·시설 기능 정지·파산** — unpaidSalary / unpaidTax 누적 시 실제 패널티 (현재 경고만 표시)
- **명성·세계 이벤트에 따른 비용 보정** — 이벤트 활성 상태가 운영비·세금에 영향을 주는 modifier 연동
- **길드 평판에 따른 보상 변동** — 명성 등급에 따라 의뢰 보상 배율 또는 수수료율 변동

---

## 0020-D 후속 (세계 이벤트 확장)

- **추가 이벤트 종류**: 타 길드 경쟁 / 도시 이벤트 / 계절 이벤트 / 지역재난 / 떠돌이 모험가
  - 현재 17종 풀 → 추가 확장 여지 있음

---

## 0020-C 후속 (가입 신청 스토리 확장)

- **동시 승인 조건** — 특정 이벤트 조합 지원자를 함께 승인해야 이벤트 완성되는 구조
- **지원자 관계 수치** — 승인 시 다른 모험가와 초기 관계 수치 연동 (rivalEventType 등)
- **반려 재등장** — 반려된 지원자가 조건 변화 후 재등장하는 흐름

---

## 0020-B 후속 (길드 명성 활용)

- **명성에 따른 지원자 변화** — 명성 등급이 높을수록 고품질 이벤트 지원자 등장 확률 증가
- **타 세력 신뢰 변화** — 명성 변동이 세력 관계 수치에 영향을 주는 연동
- **지역·도시 명성 분화** — 단일 명성 수치를 지역별로 분화 (서풍 왕국 vs 변경 지역 등)
