# 지역 데이터베이스

Guild Chronicle에 등장하는 모든 지역(Region) 데이터.
시스템 규칙은 `docs/01_SYSTEM/WORLD_SYSTEM_GUIDE.md` 참조.
몬스터 군락 연동은 `docs/02_DATABASE/MONSTER_COLONY_GUIDE.md` 참조.

---

## 데이터 구조

### 현재 구현 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string | `"region-{영문식별자}"` |
| `name` | string | 표시용 한국어 지역명 |
| `danger` | number | 위험도 수치 (0~100) |
| `control` | string | 지배 상태 (`kingdom` / `contested` / `hostile`) |

### 향후 확장 필드 (0026 이후)

| 필드 | 타입 | 설명 |
|------|------|------|
| `type` | string | 지역 유형 (plain·forest·mountain 등) |
| `terrain` | QuestTag | `terrain:*` 태그. 이벤트 엔진 연동 |
| `climate` | string | 기후 (온대·한랭·습지 등) |
| `recommendedRank` | AdventurerRank | 권장 파티 랭크 |
| `majorMonsters` | string[] | 주요 출몰 몬스터 종 ID 목록 |
| `resources` | string[] | 주요 자원·특산물 |
| `industry` | string[] | 주요 산업 |
| `population` | string | 인구 규모 (large·medium·small·none) |
| `culture` | string | 문화권 설명 |
| `religion` | string | 주요 신앙 |
| `guildBranch` | boolean | 길드 지부 존재 여부 |
| `majorQuests` | string[] | 대표 의뢰 유형 |
| `majorDungeons` | string[] | 주요 던전·유적 목록 |
| `majorFacilities` | string[] | 주요 시설 (도시·요새·항구 등) |
| `notes` | string | 지역 설명 |

## 템플릿

새 지역을 추가할 때 아래 형식을 복사해 작성한다.

```
### {지역명}

| 항목 | 내용 |
|------|------|
| ID | region-{식별자} |
| 지역명 | {한국어 이름} |
| 지역 유형 | {plain / forest / mountain / swamp / coast / dungeon / ruins / canyon / border / city_area} |
| 위험도 | {0~100} |
| 지배 상태 | {kingdom / contested / hostile} |
| 권장 랭크 | {F / E / D / C / B / A / S} |
| 기후 | {온대 / 한랭 / 열대 / 건조 / 습지} |
| 소속 국가 | {아르테니아 왕국 / 미소속 / 기타} |
| 인구 | {large / medium / small / none} |

**지형 태그**: `terrain:{값}`

**주요 몬스터**
- {종 이름} (랭크)

**주요 자원**
- {자원}

**주요 산업**
- {산업}

**특산물**
- {특산물}

**문화·종교**
{설명}

**길드 지부**: {있음 / 없음}

**대표 의뢰**
- {의뢰 유형}: {설명}

**주요 던전·유적**
- {이름}: {설명}

**지역 설명**
{서술}
```
