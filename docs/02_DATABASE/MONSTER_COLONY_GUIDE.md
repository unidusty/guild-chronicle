# 몬스터 군락 가이드

몬스터 군락의 규모·번식·이동·계절 변화·소탕·재유입에 관한 규칙.
개별 몬스터 데이터는 `docs/02_DATABASE/MONSTER_DATABASE.md` 참조.
시스템 공통 규칙은 `docs/01_SYSTEM/MONSTER_SYSTEM_GUIDE.md` 참조.

---

## 군락이란

같은 종·카테고리의 몬스터가 일정 영역에 집단을 이루어 활동하는 단위.
단독 개체(solitary)도 군락으로 취급한다 (규모: 1).

군락은 지역 위협도 계산의 기본 단위이며 의뢰 생성의 근거가 된다.

---

## 군락 규모 등급

| 등급 | 표시 | 개체 수 | 예시 |
|------|------|---------|------|
| `lone` | 단독 | 1 | 드레이크, 리치 |
| `pair` | 한 쌍 | 2~3 | 그리폰 번식 쌍 |
| `pack` | 소규모 | 4~15 | 하피 무리, 오크 분견대 |
| `colony` | 군락 | 16~60 | 고블린 기지, 슬라임 서식지 |
| `horde` | 대군 | 61~200 | 좀비 무리, 대형 쥐 떼 |
| `swarm` | 대군세 | 201+ | 대규모 침공, 고블린 왕국급 |

---

## 사회성과 군락 규모

몬스터의 `사회성(socialBehavior)` 속성이 기본 군락 규모를 결정한다.

| 사회성 | 기본 규모 | 설명 |
|--------|-----------|------|
| `solitary` | lone | 단독 개체. 번식 시에만 일시적 pair |
| `pair` | pair | 번식 쌍 유지 |
| `pack` | pack | 소규모 집단 사냥 |
| `colony` | colony | 기지 중심 집단 거주 |
| `horde` | horde | 대규모 집단. 지휘 체계 미약 |

---

## 번식 규칙

### 번식 시기

- 대부분의 종: 봄에 번식 활성화
- 예외
  - 언데드: 번식하지 않음. 소환 또는 재생
  - 골렘: 번식하지 않음. 마법사 제작
  - 트롤: 사계절 저속 번식

### 번식에 따른 규모 변화

봄 계절 갱신 시 번식 처리.

| 사회성 | 번식 규칙 |
|--------|-----------|
| `solitary` | lone 개체가 pair가 되면 다음 봄에 pack 형성 가능 |
| `pair` | pair → pack. 단, 충분한 식량이 있어야 성장 |
| `pack` | 규모 1.3~1.5배 성장. 상한에서 colony 분리 |
| `colony` | 규모 1.2~1.4배 성장. 과밀 시 pack 단위 분가 이동 |
| `horde` | 규모 1.1~1.2배 성장. swarm 직전에 대규모 이동 |

## 이동 규칙

### 이동 트리거

| 조건 | 이동 결과 |
|------|-----------|
| 식량 고갈 | 새 서식지 탐색. 방향: 취락·농경지 우선 |
| 군락 과밀 | 소규모 분파가 새 영역 확립 |
| 토벌로 규모 50% 감소 | 생존 개체가 인접 지역으로 후퇴 |
| 계절 변화 (가을→겨울) | 지하·동굴 집중 이동 |
| 상위 포식자 등장 | 도주 이동 |

### 이동 거리

| 랭크 | 이동 거리 |
|------|-----------|
| F~E | 1~3 지역 |
| D | 1~2 지역 |
| C | 1 지역 (보통 이동하지 않음) |
| B 이상 | 이동 없음 (영역 고정) |

## 계절 변화

### 봄

- 번식 처리: 모든 번식 가능 종의 규모 증가
- 하피·그리폰 번식기: 산간 지역 의뢰 위험도 상승
- 트롤 동면 해제: 이전 겨울에 동면한 트롤 영역 재활성화

### 여름

- 전체 활동 최대화
- 고블린·오크 영역 확장 이동
- 마수류 먹이 탐색 반경 확대
- 지역 위협도 피크 시기

### 가을

- 식량 확보 공격 빈도 상승
- 마을·농장 주변 군락 위협도 상승
- 겨울 이동 준비: 지하·동굴 방향 이동 시작

### 겨울

- 대부분 종 활동 50~70% 감소
- 트롤: 동면
- 언데드: 활동 증가. 리치·좀비·스켈레톤 지역 위협도 상승
- 고블린: 실내 침투. 창고·건물 내부 약탈 빈도 상승
- 드래곤 계열: 동면. 와이번·드레이크 지역 위협도 감소

## 개체 수 계산

### 순 변화 공식

```
다음 계절 개체 수 = 현재 개체 수 × (1 + 번식률 - 자연 사망률) - 토벌 수
```

### 표준 번식률·사망률

| 카테고리 | 번식률/계절 | 자연 사망률/계절 |
|----------|-------------|-----------------|
| rodent | 0.40 | 0.10 |
| goblin | 0.25 | 0.08 |
| humanoid | 0.15 | 0.05 |
| beast | 0.10 | 0.05 |
| monster | 0.08 | 0.03 |
| undead | 0.00 (소환) | 0.00 |
| golem | 0.00 | 0.00 |
| dragon | 0.05 | 0.02 |

### 봄 번식 특례

봄 계절에는 번식률이 1.5배 적용된다.

### 군락 상한

군락이 상한에 달하면 분파 이동을 처리한다.

| 등급 | 상한 | 초과 처리 |
|------|------|-----------|
| pack | 15 | colony 전환 |
| colony | 60 | pack 분파 이동 |
| horde | 200 | swarm 전환 또는 분가 이동 |

## 군락 성장 조건

### 성장 강화 요인

| 요인 | 효과 |
|------|------|
| 인근 취락·농경지 존재 | 번식률 +0.10 |
| 인근 지하 던전·유적 | 자연 사망률 -0.02 |
| 계절: 봄 | 번식률 ×1.5 |
| 토벌 없음 (2계절 이상) | 번식률 +0.05 누적 |
| 상위 포식자 부재 | 자연 사망률 -0.03 |

### 군락 감소 요인

| 요인 | 효과 |
|------|------|
| 의뢰 토벌 | 토벌 수만큼 즉시 감소 |
| 계절: 겨울 | 비언데드 번식률 0 |
| 식량 부족 | 자연 사망률 +0.15 |
| 상위 포식자 출현 | 자연 사망률 +0.20 |
| 지역 위협도 저하 의뢰 | 지역 위협도 -1 즉시 적용 |

## 완전 토벌

군락을 완전히 제거하는 조건.

### 조건

| 항목 | 기준 |
|------|------|
| 잔존 개체 | 0 |
| 특수 조건 (골렘) | 마법 핵 파괴 완료 |
| 특수 조건 (언데드) | 소환원 (묘지·유적 봉인) 제거 |
| 특수 조건 (리치) | 마법 핵 확인·파괴 포함 |

### 완전 토벌 효과

- 지역 위협도 0 처리
- 의뢰 연대기에 완전 토벌 기록
- 해당 지역 관련 의뢰 종료

## 재유입 규칙

### 자연 재유입

완전 토벌 후 일정 계절이 경과하면 새 군락이 자연 발생한다.

| 카테고리 | 재유입 최소 대기 계절 |
|----------|----------------------|
| rodent | 1계절 |
| goblin | 2계절 |
| humanoid | 3계절 |
| beast | 3계절 |
| monster | 4계절 |
| undead | 2계절 (소환원 미제거 시 즉시) |
| golem | 재유입 없음 (재생성 시 별도 의뢰 발생) |
| dragon | 5계절 이상 |

### 재유입 크기

자연 재유입은 pack 이하 규모로 시작한다.

### 재유입 방지 조건

| 조건 | 효과 |
|------|------|
| 인근 길드 상주 | 재유입 확률 -50% |
| 지역 위협도 주기적 점검 의뢰 | 재유입 탐지 후 조기 대응 |
| 언데드 소환원 봉인 완료 | 언데드 재유입 차단 |
| 골렘 창조 마법사 제거 | 골렘 재생성 방지 |

## 군락과 의뢰 연동

### 의뢰 자동 생성 기준

지역 위협도가 갱신될 때마다 의뢰 생성 여부를 판단한다.

| 위협도 변화 | 의뢰 생성 |
|-------------|-----------|
| 1 이상 유지 | F~E 정기 방제 의뢰 |
| 2 이상 상승 | D 토벌 의뢰 |
| 3 이상 상승 | C 소탕 의뢰 |
| 4 이상 상승 | B 대토벌 의뢰 (긴급 분류) |
| 5 도달 | S급 긴급 의뢰. 왕실·군 협조 가능 |

### 토벌 의뢰 완료 효과

| 의뢰 결과 | 군락 변화 |
|-----------|-----------|
| 대성공 | 개체 수 70~100% 감소 |
| 성공 | 개체 수 50~70% 감소 |
| 간신히 성공 | 개체 수 30~50% 감소 |
| 철수 | 개체 수 변화 없음 |
| 실패 | 개체 수 변화 없음 (군락 자신감 상승 → 위협도 +1) |
| 대실패 | 위협도 +1 즉시 적용 |

### 토벌 의뢰 목표 구성

| 군락 규모 | 목표 |
|-----------|------|
| lone, pair | 개체 제거 |
| pack | 우두머리 제거 + 잔존 개체 토벌 |
| colony | 기지 파괴 + 지도층 제거 |
| horde | 분산 후 순차 토벌 (복수 의뢰 분할) |
| swarm | 토벌 단독 불가. 지원 의뢰 + 대피 + 국가 대응 병행 |
