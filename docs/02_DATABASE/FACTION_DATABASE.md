# 세력 데이터베이스

Guild Chronicle에 등장하는 모든 세력(Faction) 데이터.
세력은 의뢰 발주·세계 이벤트·길드 관계의 주체다.
세계 구조 설명은 `docs/01_SYSTEM/WORLD_SYSTEM_GUIDE.md` 참조.

---

## 데이터 구조

### 현재 구현 상태

세력 데이터는 현재 코드에 직접 구현되지 않았다.
이 문서는 0026 세계 시스템 구현을 위한 설계 기준이다.

### 세력 데이터 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | string | `"faction-{영문식별자}"` |
| `name` | string | 표시용 한국어 세력명 |
| `type` | FactionType | 세력 종류 |
| `leader` | string | 대표 인물 (이름 또는 직책) |
| `headquarters` | string | 본거지 (지역 ID 또는 도시명) |
| `influence` | string[] | 영향 지역 (region ID 목록) |
| `goal` | string | 세력 목표 |
| `alignment` | string | 성향 |
| `allies` | string[] | 우호 세력 ID |
| `enemies` | string[] | 적대 세력 ID |
| `guildRelation` | string | 길드와의 기본 관계 |
| `traits` | string[] | 대표 특징 |
| `notes` | string | 추가 설명 |

### 세력 종류 (FactionType)

| 값 | 표시 |
|----|------|
| `kingdom` | 국가 |
| `noble` | 귀족 |
| `knightOrder` | 기사단 |
| `merchantGuild` | 상인 길드 |
| `mageTower` | 마탑 |
| `church` | 종교 |
| `crimeOrg` | 범죄 조직 |
| `adventurerGuild` | 모험가 길드 |
| `monster` | 몬스터 세력 |

### 성향 (alignment)

| 값 | 표시 |
|----|------|
| `lawful_good` | 질서 선 |
| `neutral_good` | 중립 선 |
| `chaotic_good` | 혼돈 선 |
| `lawful_neutral` | 질서 중립 |
| `true_neutral` | 완전 중립 |
| `chaotic_neutral` | 혼돈 중립 |
| `lawful_evil` | 질서 악 |
| `neutral_evil` | 중립 악 |
| `chaotic_evil` | 혼돈 악 |

### 길드와의 관계 (guildRelation)

| 값 | 표시 | 설명 |
|----|------|------|
| `patron` | 후원 | 의뢰 주 발주처. 높은 보상 |
| `ally` | 우호 | 정보·자원 협력 |
| `neutral` | 중립 | 이해관계에 따라 협력 또는 무관 |
| `suspicious` | 경계 | 감시하거나 경쟁적 |
| `hostile` | 적대 | 길드 활동 방해 또는 적으로 등장 |
| `unknown` | 미접촉 | 아직 관계가 형성되지 않음 |

## 템플릿

새 세력을 추가할 때 아래 형식을 복사해 작성한다.

```
### {세력명}

| 항목 | 내용 |
|------|------|
| ID | faction-{식별자} |
| 세력명 | {이름} |
| 종류 | {세력 종류} |
| 대표 인물 | {이름 또는 직책} |
| 본거지 | {지역명 또는 도시명} |
| 성향 | {성향} |
| 길드 관계 | {guildRelation 값} |

**영향 지역**: {region-id 목록 또는 설명}

**목표**
{세력이 추구하는 목표}

**우호 세력**: {세력명}
**적대 세력**: {세력명}

**대표 특징**
- {특징}

**길드와의 관계 상세**
{상세 설명}

**비고**
{추가 설명}
```

### 아르테니아 왕실

| 항목 | 내용 |
|------|------|
| ID | faction-artenia-crown |
| 세력명 | 아르테니아 왕실 |
| 종류 | kingdom |
| 대표 인물 | 아르테니아 국왕 (이름 미확정) |
| 본거지 | 아르테니아 왕도 |
| 성향 | lawful_neutral |
| 길드 관계 | patron |

**영향 지역**: region-westfield, region-westcanal (직접 통제), 기타 왕국 영토 전역 (간접)

**목표**
왕국의 안정과 영토 유지. 귀족 분란 억제. 국경 방어.

**우호 세력**: 아르테니아 정규기사단, 모험가 길드 연합, 빛의 성교회
**적대 세력**: 북부 고블린 왕국, 국경 도적 연맹

**대표 특징**
- 모험가 길드 제도를 공식 인정하고 지원한다
- 국경 방위를 위해 길드에 토벌·호위 의뢰를 대량 발주
- 왕실 직접 의뢰는 일반보다 보상이 높지만 실패 시 명성 패널티가 크다
- 정치적 판단에 따라 길드에 민감한 의뢰를 위임하는 경우가 있다

**길드와의 관계 상세**
현재 길드의 주요 의뢰 발주처 중 하나. 공식 후원 관계는 아니나 왕국 치안 유지에 협력하는 관계다.
향후 길드 명성이 높아지면 왕실 직접 의뢰·왕실 의뢰 전용 등급이 해금될 수 있다.

### 아르테니아 정규기사단

| 항목 | 내용 |
|------|------|
| ID | faction-royal-knights |
| 세력명 | 아르테니아 정규기사단 |
| 종류 | knightOrder |
| 대표 인물 | 기사단장 (이름 미확정) |
| 본거지 | 왕도 기사단 본부 |
| 성향 | lawful_good |
| 길드 관계 | ally |

**영향 지역**: 왕국 전역. 국경 지대 전초기지 다수

**목표**
왕국 방위. 귀족 반란 진압. 몬스터 대토벌 지휘.

**우호 세력**: 아르테니아 왕실, 빛의 성교회
**적대 세력**: 북부 고블린 왕국, 국경 도적 연맹

**대표 특징**
- 대규모 토벌은 기사단이 직접 처리하지만 정찰·선봉은 길드에 의뢰
- B랭크 이상 의뢰를 기사단 협조 의뢰로 발주하는 경우가 있다
- 기사단원이 실종·포로가 되면 구조 의뢰를 길드에 긴급 발주
- 기사단 훈련장과 연계한 특수 훈련 의뢰 발주 가능

**길드와의 관계 상세**
실용주의적 협력 관계. 기사단은 정면 전력이고 길드는 정보·정찰·특수임무 역할로 분업한다.
대규모 레이드(0027) 구현 시 공동 편성 파트너가 된다.

### 왕국 대상인 연합

| 항목 | 내용 |

| ID | faction-merchant-union |
| 세력명 | 왕국 대상인 연합 |
| 종류 | merchantGuild |
| 대표 인물 | 연합 의장 (이름 미확정) |
| 본거지 | 아르테니아 왕도 상업구 |
| 성향 | true_neutral |
| 길드 관계 | patron |

**영향 지역**: 왕국 주요 교역로 전역. region-westcanal, region-borderpass 중심

**목표**
교역 안전 확보. 이윤 극대화. 길드 보호 계약 확대.

**우호 세력**: 아르테니아 왕실 (교역세 납부), 모험가 길드 연합
**적대 세력**: 국경 도적 연맹

**대표 특징**
- 호위·배달 의뢰의 최다 발주처
- 상단 규모에 따라 요구 파티 등급이 다르다
- 정보 거래에 적극적. 지역 정세를 길드에 유상 제공
- 이익에 따라 선택. 위험한 의뢰는 보상을 높게 제시한다

**길드와의 관계 상세**
순수 거래 관계. 성공률이 높은 길드에 지속적으로 의뢰를 발주한다.
대상인 연합의 신뢰를 얻으면 독점 의뢰·내부 정보가 제공된다.

### 왕립 마법사 탑

| 항목 | 내용 |
|------|------|
| ID | faction-mage-tower |
| 세력명 | 왕립 마법사 탑 |
| 종류 | mageTower |
| 대표 인물 | 탑주 (이름 미확정) |
| 본거지 | 왕도 마법사 탑 |
| 성향 | lawful_neutral |
| 길드 관계 | neutral |

**영향 지역**: 왕도 및 마법 연구 지점. 고대 유적 조사권 주장

**목표**
마법 기술 연구·보존. 위험 마법 봉인. 고대 지식 복원.

**우호 세력**: 아르테니아 왕실 (공식 지원)
**적대 세력**: 없음 (중립 유지)

**대표 특징**
- 탐사·발굴 의뢰를 길드를 통해 발주
- 특정 몬스터 소재·마석·유물을 구매하는 의뢰를 꾸준히 낸다
- 마법 지원이 필요한 의뢰에 마법사 탑 소속 마법사 파견 가능
- 고대 유적 접근권은 탑의 허가가 필요하다는 입장

**길드와의 관계 상세**
이해관계에 따른 협력. 탐사 의뢰와 유물 수집 의뢰가 주 접점이다.
탑의 신뢰를 얻으면 마법 지원, 희귀 마법 재료 거래 루트가 열린다.
