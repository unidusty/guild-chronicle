# 03. GAME RULES

아직 정하지 않은 수치는 `미정`으로 표시한다.

- 모험가는 랜덤으로 생성된다.
- 종족과 성별에 따라 이름과 초상화 풀이 달라진다.
- 초상화는 폴더에 존재하는 파일 수만큼 자동 확장된다.
- 생성된 초상화 ID는 저장 데이터에 기록한다.
- 능력치 상한은 낮게 유지하고 조합 차이를 크게 만든다.
- 소속감은 길드 잔류와 이탈에 영향을 준다.
- 사망·은퇴·이탈한 인물의 기록은 삭제하지 않는다.
- 의뢰 등급 후보는 D, C, B, A, S다.
- 의뢰는 즉시 끝나지 않고 게임 시간 동안 진행된다.
- 여러 의뢰가 동시에 진행될 수 있다.
- 주요 사건은 날짜, 관련 인물, 장소와 함께 저장한다.
- 1계절은 30일이며 봄·여름·가을·겨울 순서로 진행된다.
- 겨울이 끝나면 연도가 1 증가하고 봄 1일부터 다시 시작한다.
- 하루 진행마다 진행 중인 의뢰의 남은 일수가 1 감소한다.
- 남은 일수가 0이 되면 의뢰는 완료 처리된다.
- 연대기에는 의미 있는 사건만 기록한다. 단순 날짜 변경은 기록하지 않는다.
- 기록 대상 예시: 길드 입단, 의뢰 완료, 의뢰 실패, 부상, 회복, 훈련 완료, 승급, 사망.
