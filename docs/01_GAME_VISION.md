# 01. GAME VISION

## 프로젝트명
**Guild Chronicle** / 한국어 가칭 **길드 연대기**

## 한 줄 정의
플레이어가 판타지 세계의 모험가 길드 마스터가 되어 사람과 의뢰를 관리하고, 길드와 모험가들의 역사를 만들어 가는 PC 경영 시뮬레이션.

## 플레이어의 역할
플레이어는 영웅이 아니다. 길드 마스터다.

- 어떤 모험가를 받아들일지
- 누구를 같은 파티로 묶을지
- 어떤 의뢰를 누구에게 맡길지
- 부상과 실패를 감수할지
- 길드의 자원을 어디에 투자할지

플레이어는 전투를 직접 조작하지 않는다. 결정과 관리의 결과가 전투와 사건으로 나타난다.

## 핵심 재미
1. 평범한 신입에서 전설을 발견하는 재미
2. 능력·관계·성격을 고려해 파티를 구성하는 재미
3. 자동 진행되는 의뢰의 결과와 이변을 지켜보는 재미
4. 길드와 모험가의 연대기가 쌓이는 재미

## 핵심 루프
모험가 모집 → 파티 구성 → 의뢰 검토 → 의뢰 배정 → 자동 진행 → 결과 확인 → 보상·부상·관계·연대기 반영 → 길드 성장

## UI 철학
목표는 **판타지 Football Manager**다.

지향: 넓은 PC 화면, 표, 목록, 보고서, 기록, 정보 비교, 중세 길드 사무실 분위기.

지양: 모바일 게임형 거대 카드, 뽑기 희귀도 연출, 과도한 강화 버튼, 캐릭터 전시 중심 화면.

## 절대 만들지 않을 것
- 직접 조작 실시간 전투
- 모바일 자동 전투 RPG 구조
- 캐릭터 뽑기와 중복 합성
- 희귀도 중심 수집 구조
- 일러스트 수량에 콘텐츠가 제한되는 구조
