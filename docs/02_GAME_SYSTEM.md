# 02. GAME SYSTEM

## 모험가
종족, 성별, 이름, 초상화, 직업, 능력치, 잠재력, 숨은 특성, 성격, 소속감, 관계, 부상, 상태, 개인 연대기.

## 파티
고정 파티와 임시 파티를 지원한다. 파티에도 리더, 활약 기록, 경험, 랭크를 둘 수 있다.

## 의뢰
등급, 장소, 목표, 위험 요소, 보상으로 구성한다. 진행 중 숨은 강적, 부상, 지원 요청, 다른 길드 조우 같은 이변이 발생할 수 있다.

의뢰는 세 단계(이동 → 수행 → 귀환)로 나뉘며 매일 진행된다. 이변이 발생하면 플레이어가 계속·철수·지원 파견 중 하나를 결정한다. 완료 시 결과 등급(대성공·성공·간신히 성공·철수·실패·대실패)이 정해지고 보상·연대기·모험 기록이 남는다.

## 모험 기록 (Adventure Scene)
의뢰 진행의 날별·사건별 장면(Scene) 기록이다. 출발부터 귀환까지 모든 사건이 문단 단위 한국어 장면으로 기록되며, 의뢰가 완료된 후에도 의뢰 연대기에서 확인할 수 있다. 각 Scene은 2~8 문단으로 구성되며 2~4명의 모험가가 직접 등장한다. 내러티브는 실제 게임 상태(파티원, 적 정보, 이벤트 결과)에서 파생되며 임의의 사실을 만들지 않는다.

## 전투
자동 계산한다. 플레이어는 파티 조합, 장비, 정보, 보급, 후퇴 기준을 관리한다.

## 길드 운영
명성, 자금, 물자, 길드원, 지역 평판, 시설, 직원, 전리품 매입, 제작과 판매.

## 직원
카운터 직원은 반복적인 의뢰 배분을 자동화한다. 중요한 사건과 주요 의뢰는 길드 마스터가 직접 결정한다.

## 시간 진행
하루 진행 버튼으로 게임 내 하루를 진행한다. 1계절은 30일이며 봄·여름·가을·겨울 4계절이 1년을 구성한다. 하루가 지나면 진행 중인 의뢰의 남은 일수가 감소하고, 0이 된 의뢰는 완료 처리되며 참여 파티와 모험가가 대기 상태로 복귀한다.

## 연대기
길드 연대기와 개인 연대기를 분리하되 주요 사건은 양쪽에 연결해 기록한다. 의미 있는 사건만 기록하며 단순 날짜 변경은 기록하지 않는다. 대시보드에는 최신 3개 항목만 표시하고 전체 기록은 연대기 전용 화면에서 확인한다.

## 기록 보관
활동 중, 은퇴, 이탈, 실종, 사망 상태를 지원하며 기록은 삭제하지 않는다.
