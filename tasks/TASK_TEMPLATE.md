## 문서 업데이트

기능을 변경했다면 아래 기준으로 관련 문서를 함께 갱신한다.

- 변경 사항이 없는 문서는 수정하지 않는다.
- 작업 내용에 따라 필요한 문서만 선택하여 갱신한다.

업데이트 대상 예시

- `docs/00_PROJECT/PROJECT_STATUS.md` — 완료 항목, 버전, 다음 작업
- `docs/00_PROJECT/PROJECT_TERMINOLOGY.md` — 새 용어·타입
- `docs/00_PROJECT/PROJECT_OVERVIEW.md` — 핵심 시스템 변경 시
- `docs/00_PROJECT/PROJECT_RULES.md` — 새 개발 원칙 추가 시
- `docs/00_PROJECT/PROJECT_WORKFLOW.md` — 워크플로우 변경 시
- `docs/00_PROJECT/ROADMAP.md` — 완료·예정 항목 변경 시
- `docs/` 하위 관련 설계 문서
