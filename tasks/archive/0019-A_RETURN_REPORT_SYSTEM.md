# 목적

0019의 첫 번째 업데이트로 길드 재정 시스템의 기반이 되는 **귀환 보고 및
정산(Return Report & Settlement)** 시스템을 구축한다.

의뢰 완료 → 귀환 → 귀환 보고 → 정산 → 완료 흐름으로 변경한다.

------------------------------------------------------------------------

# 구현 범위

## 1. 귀환 보고 시스템

-   의뢰 완료 시 즉시 정산하지 않는다.
-   Return Report 생성
-   길드장이 보고 확인 후 정산

## 2. 의뢰 완료 흐름 변경

기존: 의뢰 완료 → 보상 지급 → 창고 반영 → 파티 대기

변경: 의뢰 완료 → 귀환 보고 생성 → 정산 대기 → 길드장 정산 → 정산 완료 →
파티 대기

## 3. 자동 지급 금지

정산 완료 전에는 길드 자금, 파티 보수, 창고 반영, 파티 idle 처리를 하지
않는다.

## 4. 귀환 보고 화면

-   의뢰 결과
-   수행 파티
-   수행 기간
-   의뢰품
-   획득 전리품
-   총 의뢰 보수
-   길드 수수료
-   파티 지급액
-   파티 상태

## 5. 의뢰품

전리품과 구분하며 정산 시 의뢰인에게 자동 인계한다.

## 6. 전리품

기본적으로 수행 파티 소유이다.

## 7. 길드 매입

전리품 선택 → 길드 매입 → 길드 자금 차감 → 길드 창고 이동까지만
구현한다.

## 8. 의뢰 보수 정산

총 보수 → 길드 수수료(10%) → 수행 파티 지급

## 9. 파티 상태

in_progress → returning → waiting_settlement → idle

## 10. 정산 완료

-   귀환 보고 제거
-   파티 idle
-   전리품 이동
-   길드 자금 반영
