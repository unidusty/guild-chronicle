# Guild Chronicle

판타지 세계의 모험가 길드를 운영하는 PC 경영 시뮬레이션 게임.

## 현재 버전

**012-A — 파티 관리 기반 및 모험가 풀 확장**

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 표시되는 주소로 접속한다. 기본 주소는 `http://localhost:5173`이다.

## 빌드 확인

```bash
npm run check
npm run build
```

## 기술 스택

- React
- TypeScript
- Vite
- 순수 CSS

1차 목표는 브라우저 기반 싱글 플레이 MVP다. 데스크톱 앱 패키징은 게임 루프가 작동한 뒤 Tauri 적용을 검토한다.
